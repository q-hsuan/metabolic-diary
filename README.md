# 雙軌代謝日記

記錄血糖、血酮與三餐飲食的手機網頁 App，資料可同步到 Google 雲端，讓家人在自己的手機上唯讀查看。

**App 網址：** <https://q-hsuan.github.io/metabolic-diary/>

---

## 功能

- **醣酮紀錄**：早上空腹、午時空腹、餐後 2 時、餐後 3 時的血糖與血酮，自動計算 GKI 指數與燃脂等級，並畫出雙軸趨勢圖。
- **三餐紀錄**：早、中、晚餐內容與碳水比例，可拍照或從相簿選照片（自動壓縮）。
- **雙軌每日對照**：同一天的醣酮數值與飲食並排顯示，可隨時修改、刪除。
- **單位切換**：mg/dL ↔ mmol/L。
- **匯出 CSV**：右上角 ⬆️ 按鈕，可用 Excel 開啟。
- **Google 雲端共用**：主要記錄者的手機自動上傳，其他人用分享連結唯讀查看。

---

## 誰用什麼方式開

| 角色 | 開啟方式 | 能做什麼 |
|---|---|---|
| **主要記錄者** | App 網址，已在 ☁️ 完成設定 | 新增、修改、刪除，自動上傳到雲端 |
| **家人** | 「分享連結」（網址後面帶 `?view=...`） | 只能看，按「重新整理」取得最新資料 |

> 同一時間只能有**一支手機**負責上傳。每次上傳都會用那支手機的資料取代雲端資料，兩支手機都上傳會互相覆蓋。

---

## 加到手機主畫面

- **iPhone**：用 Safari 開網址 → 下方「分享」→「加入主畫面」。
- **Android**：用 Chrome 開網址 → 右上「⋮」→「安裝應用程式」或「新增至主畫面」。

> iPhone 主畫面的 App 和 Safari 的資料是分開的。主要記錄者請固定用同一個入口記錄。

## 雲端共用設定

### 架構

```
主要記錄者的手機 ──上傳（需寫入密碼）──▶ Google Apps Script ──▶ 你的 Google 雲端硬碟
                                               │                  metabolic-diary-data.json
家人的手機 ◀─────────── 唯讀讀取 ──────────────┘
```

### 1. 部署 Google Apps Script（只需一次，已完成）

1. 到 <https://script.google.com> 新增專案，把本倉庫 [`google-apps-script.gs`](google-apps-script.gs) 的內容全部複製貼上。
2. 在 Apps Script 編輯器裡，把 `WRITE_KEY` 那行的 `請改成你自己的密碼` 改成自己的密碼並儲存。
   ⚠️ 密碼只改在 Apps Script 裡，不要改 GitHub 上的檔案，否則密碼會公開。
3. 「部署」→「新增部署作業」→ 類型「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 授權後複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。

### 2. 設定主要記錄者

在記錄者的手機打開 App → 右上角 ☁️：

1. 貼上 Apps Script 網址、輸入寫入密碼。
2. 按「**儲存並上傳**」，看到「✓ 已上傳」即完成。

也可以在已設定好的手機按「**複製記錄者設定連結**」傳給對方，對方點開就自動完成設定。iPhone 主畫面 App 的話，請把整個設定連結貼到 ☁️ 的「網址」欄再按「儲存並上傳」。

⚠️ 記錄者設定連結含寫入密碼，只傳給記錄者本人。

### 3. 分享給家人

在記錄者的手機 ☁️ 按「**複製分享連結**」，用 LINE 傳給家人，請他們加入書籤。分享連結不含密碼，只能看不能改。

### 4. 換人記錄或停止上傳

在不再負責記錄的手機 ☁️ 按「**此手機停止上傳**」，之後改用分享連結查看。

## 隱私說明

| 東西 | 存放位置 | 誰看得到 |
|---|---|---|
| App 程式 | GitHub（公開） | 任何人，但裡面沒有任何人的紀錄 |
| 紀錄與照片 | 記錄者手機 + Google 雲端硬碟 | 只有拿到**分享連結**或 **Apps Script 網址**的人 |
| 寫入密碼 | Apps Script + 記錄者手機 | 只有你和記錄者 |

- 陌生人打開 App 網址，看到的是他自己手機上的空白日記。
- **不要把 Apps Script 網址、分享連結、記錄者設定連結貼到公開的地方。**
- GitHub 上的 `google-apps-script.gs` 只放範本，`WRITE_KEY` 必須維持 `請改成你自己的密碼`，**不要把真正的密碼寫進去**。
- 若懷疑連結外流：Apps Script「部署」→「管理部署作業」→ **封存**，舊連結立即失效。重新部署後再設定一次記錄者手機即可，雲端硬碟裡的資料不會消失。

## 備份與還原

### 自動備份（Google 雲端硬碟）

主要記錄者的手機每次上傳時，Apps Script 會先把雲端原本的資料另存到雲端硬碟的 **`metabolic-diary-backups`** 資料夾：

- **每日備份** `backup-2026-10-28.json`：每天第一次上傳前存一份。
- **少紀錄前備份** `backup-2026-10-28_210000_少了2筆前.json`：只要這次上傳會讓雲端少掉任何一筆紀錄（包括正常刪除），就先多存一份。
- 備份保留 **60 天**，之後移到垃圾桶（垃圾桶裡還能再救 30 天）。

### 手動備份（手機）

☁️ →「**下載備份檔**」：把這支手機的全部紀錄（含照片）存成 `.json` 檔。iPhone 會跳出分享選單，可選「儲存到檔案」或傳到 LINE。

### 還原

1. 到 Google 雲端硬碟的 `metabolic-diary-backups` 資料夾，找到要還原的那天，下載備份檔；或使用自己下載的備份檔。
2. 把檔案傳到主要記錄者的手機（例如 LINE 傳給自己 → 儲存到「檔案」）。
3. App ☁️ →「**從備份檔還原**」→ 選該檔案 → 確定。

還原**只會補回手機裡缺少的紀錄**，不會刪除或覆蓋現有紀錄。已經存在的同一筆紀錄會保留手機上的版本。

---

## 注意事項

- 照片會跟資料一起上傳，累積很多張後雲端檔案會變大，上傳可能變慢。
- 手機資料存在瀏覽器裡，清除瀏覽器資料或換手機會不見。可以用上面的備份檔還原。
